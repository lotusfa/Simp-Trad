支援純文字同 text-based 檔：.txt / .md / .csv / .tsv / .srt / .vtt / .ass / .json / .yaml / .html / .xml / 同埋常見 code、log、字幕、設定檔。亦支援 .epub（書內轉換，下載仍係 EPUB）。可以一次過多個檔。唔支援 Word/PDF/圖片等二進制格式。

Description

This is an open-source, offline Simplified ↔ Traditional Chinese converter. Conversion runs entirely in your browser with OpenCC dictionaries (via opencc-js)—no server round-trip after the page loads.
