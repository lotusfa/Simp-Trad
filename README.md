# 簡繁轉換 (simp_trad)

Offline Simplified ↔ Traditional Chinese converter for [toolbox.lotusfa.com](https://toolbox.lotusfa.com/).

Pure client-side JS (OpenCC via opencc-js). UI matches the IPA / toolbox theme.

Conversion engine: [OpenCC](https://github.com/BYVoid/OpenCC) (Apache-2.0) via [opencc-js](https://github.com/nk2028/opencc-js) (MIT).
